# Profile icon

`profile-active.svg` is exported from Lucide React `UserRound` (ISC license; see LICENSE.txt).
The 72×72 PNG is used by the profile identity card. Other existing PNG files are retained legacy tab assets.

Rebuild: `rsvg-convert -w 72 -h 72 profile-active.svg -o profile-active.png`.

## 跟踪

tracking-normal.png / tracking-active.png 为本项目绘制的书签线性图标，采用 24×24 坐标、1.7 线宽，rsvg-convert 导出 72×72。用于推理/跟踪底部菜单。
